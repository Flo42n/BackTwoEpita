# Back Two EPITA

Back Two EPITA is a cooperative 2D puzzle adventure developed with Unity and C# as part of a group project at EPITA.

The game is designed for two players who must explore different historical environments, interact with objects and solve puzzles together to progress through the adventure.

## Features

- Two-player cooperative gameplay
- Multiplayer connections using Mirror Networking
- Exploration of medieval and Egyptian environments
- Interactive puzzles and riddles
- Dialogue and object interaction systems
- Character movement and animations
- Sound effects and visual feedback during puzzles

## Gameplay

Players explore different areas and solve puzzles based on their environment.

The game includes several types of challenges, such as activating objects in the correct order, interpreting clues and coordinating actions between players.

Both players must communicate and cooperate to complete the challenges.

## Technologies

- **Unity 6** for game development
- **C#** for gameplay programming
- **Mirror** for multiplayer networking
- **Unity 2D** for environments, animations and interactions

## Installation and Usage

The project was developed using Unity `6000.0.26f1`.

To open the game:

1. Clone the repository.
2. Open the project folder in Unity Hub.
3. Open the project with a compatible Unity version.
4. Load `Assets/Scenes/MainScene.unity`.
5. Start the game from the Unity Editor.

The multiplayer interface allows one player to host a session and another to connect using the host's IP address or local network discovery.

### Controls

- **Arrow keys:** Move the character
- **E:** Interact with objects
- **Space:** Close dialogues

## Project Structure

- `Assets/Script/`: gameplay, puzzles, networking and player interactions
- `Assets/Scenes/`: game scenes
- `Assets/Art/`: characters and environment assets
- `Assets/Animation/`: character and object animations
- `Assets/Audio/`: music and sound effects
- `Assets/UI/`: interface assets
- `Packages/`: Unity project dependencies
- `ProjectSettings/`: Unity project configuration

## About the Project

Back Two EPITA was developed as a team project, combining game programming, puzzle design, multiplayer systems and visual development.

It was an opportunity to work on a complete game while learning how to organize a collaborative development project and integrate different gameplay systems.
